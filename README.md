# Yik Yu Ng - Personal Academic Website

This repository contains the source for [yyn-anson.github.io](https://yyn-anson.github.io/), an academic portfolio covering research, publications, experience, projects, and selected hobbies.

The site is built with Hugo and Hugo Blox and is deployed through GitHub Pages.

## Local development

Install the extended edition of Hugo, then run:

```bash
hugo server
```

The production build used by GitHub Pages is defined in `.github/workflows/publish.yaml`.
